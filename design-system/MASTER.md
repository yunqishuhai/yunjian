# 云笺 Android 界面约定

使用原生 Jetpack Compose / Material 3，内容优先，支持浅色、深色及系统字体缩放。

- 默认雾蓝主色、冷白表面；另有冰蓝、竹青、浅紫、樱粉配色。配色与跟随系统／浅色／深色模式分别选择，气泡、按钮、侧栏使用对应语义颜色。
- 统一系统字体、字号与行高，主要点击区域至少 48dp。
- 聊天两侧显示对应账号头像，连续发送者分组占位，时间按间隔或跨日分组。
- 设置为可滚动的原生侧栏，账号管理、导出、背景与更新使用独立面板。
- 背景只影响消息区域，气泡和输入栏保持可读的主题表面。
- 页面与按压使用 120–220ms 克制过渡，遵循系统动画比例。
- 应用图标使用维护者指定的插画，保留原画风；图标打包与隐私清理分开处理，不因排除账号数据而替换品牌素材。资源不保留照片元数据，素材说明见 NOTICE.md。
